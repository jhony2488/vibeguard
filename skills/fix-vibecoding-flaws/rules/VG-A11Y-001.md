# VG-A11Y-001 — `<img>` without `alt`

**Domain:** A11Y · **Severity:** Low

## What VibeGuard flags

An `<img>` element with no `alt` attribute — screen readers announce the file
name or nothing, and the image fails WCAG 1.1.1.

## Secure rewrite

Describe the image's purpose; mark decorative images explicitly.

```jsx
// before
<img src="/avatar.png" />
<img src="/divider.svg" />

// after
<img src="/avatar.png" alt="Profile photo of Ana" />
<img src="/divider.svg" alt="" />   {/* decorative — empty alt on purpose */}
```

- `alt` describes _function_, not appearance ("Search" not "magnifying glass").
- `alt=""` is correct for purely decorative images — never omit it.

## Verify

Re-run `vibeguard_scan_file` — every `<img>` now carries `alt` (empty counts).
