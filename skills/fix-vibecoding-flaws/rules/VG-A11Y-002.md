# VG-A11Y-002 — Non-semantic interactive element

**Domain:** A11Y · **Severity:** Low

## What VibeGuard flags

A `<div>`/`<span>` with `onClick` but no `role`/`tabIndex` — invisible to
keyboards (no Tab focus, no Enter activation) and to screen readers.

## Secure rewrite

Prefer the semantic element; polyfill only when you truly can't.

```jsx
// before
<div onClick={save}>Save</div>

// after — semantics, focus, and key handling for free
<button onClick={save}>Save</button>

// if a native element is impossible:
<div role="button" tabIndex={0} onClick={save}
     onKeyDown={(e) => e.key === 'Enter' && save()}>Save</div>
```

- `<button>` handles Enter _and_ Space, focus rings, and disabled states —
  the manual version has to re-implement all of it.
- Same rule applies to clickable `<li>`/`<a onClick>` without `href`.

## Verify

Re-run `vibeguard_scan_file` — finding clears once `role`/`tabIndex` exist or
the element is semantic.
