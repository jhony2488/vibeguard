# VG-A11Y-003 — Broken heading hierarchy

**Domain:** A11Y · **Severity:** Low

## What VibeGuard flags

Heading levels jumping (e.g. `h1 → h4`) — screen-reader users navigate by the
heading outline; skipped levels make the page structure lie.

## Secure rewrite

Fill the gap or restructure the outline — style with CSS, not heading level.

```jsx
// before
<h1>Dashboard</h1>
<h4>Revenue</h4>   {/* jumps h1 → h4 */}

// after
<h1>Dashboard</h1>
<h2>Revenue</h2>

// if the *look* of h4 was the goal:
<h2 className="text-sm">Revenue</h2>
```

- One `h1` per page; each following level nests (+1 at a time).
- Never pick a heading tag for its font size.

## Verify

Re-run `vibeguard_scan_file` — the heading sequence climbs without gaps.
