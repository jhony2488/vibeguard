# VG-A11Y-004 — Insufficient color contrast

**Domain:** A11Y · **Severity:** Low

## What VibeGuard flags

A `color`/`background` pair whose contrast ratio is below WCAG AA (4.5:1 for
normal text, 3:1 for large text) — unreadable for low-vision users and in
bright light.

## Secure rewrite

Darken the text or lighten the background until the ratio passes.

```js
// before — #999 on #eee ≈ 2.0:1
{ color: '#999999', background: '#eeeeee' }

// after — #595959 on #eee ≈ 6.0:1
{ color: '#595959', background: '#eeeeee' }
```

- Large text (≥18pt / ≥14pt bold) may target 3:1 — aim for 4.5:1 anyway.
- Don't rely on hover/focus states having better contrast; base must pass.

## Verify

Re-run `vibeguard_scan_file` — the computed ratio for the pair is ≥ 4.5:1.
